# Security Policy

## Supported Versions

Only the latest release of Salah receives active security patches.

| Version | Supported |
| :--- | :--- |
| `1.0.x` | :white_check_mark: |
| `< 1.0.0` | :x: |

---

## Reporting a Vulnerability

We take the security of Salah and its users seriously. Although Salah does not host user accounts, store passwords, or operate backend servers, security vulnerabilities in Android components, cryptography, local data handling, or network parsing are promptly investigated.

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Report via **GitHub Private Vulnerability Reporting** directly on the repository:
   https://github.com/abbasahamed/salah-app/security/advisories/new
3. Alternatively, contact the maintainer directly via GitHub profile contact information.

### What to Include in Your Report
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) code.
- Affected device types, Android OS versions, or build variants.
- The potential impact on user privacy or application integrity.

### Response Timeline
- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Remediation & Patch Release:** Coordinated disclosure and release within 14 days of triage.
